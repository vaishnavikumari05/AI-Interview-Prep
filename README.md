# AI Interview Prep

AI Interview Prep is a web application that helps users practice interview questions for different roles.

## Features

- Frontend Developer Questions
- Backend Developer Questions
- Full Stack Developer Questions
- Python Developer Questions
- Interview Timer
- Responsive User Interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## How to Run

1. Clone the repository
2. Install dependencies

```bash
npm install
```

3. Start the server

```bash
npm start
```

4. Open the application in your browser
